## 安装

### 从 GitHub 直接装（推荐，市场里也可以这么填）

```bash
dsh plugin install github:Ieckseyr/DSH-wyyyy
```

或者在 Harness 的 **设置 → 插件 → 添加** 里选「从仓库安装」，填：

```
https://github.com/Ieckseyr/DSH-wyyyy
```

### 手动装进某个 profile

把仓库放到任意目录，然后在 Harness 里让 Plugin Manager 安装这个目录，
或者直接 `plugin_manager install_bundle`（路径指向仓库根目录）。

装完刷新页面，右上角出现音符图标。

### 关于插件市场

插件市场（dshmarket）的安装源只认精选列表
[awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) 里的条目，
所以「上架」= 往那个仓库提一个 YAML 文件（`data/plugins/<owner>__<repo>.yml`）。

本仓库的条目已经写好了：[`docs/catalog-entry.yml`](docs/catalog-entry.yml)。
上架需要满足两个硬条件，缺一不可：

1. 仓库创建满 **1 天**（CI 自动检查，今天建今天提会被打回）；
2. 仓库加上 `dsh-plugin` topic（Settings → Topics）。

两者满足后，把 `docs/catalog-entry.yml` 的内容提交到
`awesome-dsh-plugin` 的 `data/plugins/Ieckseyr__DSH-wyyyy.yml` 即可。

在这之前，用上面的「从仓库安装」照样能装——市场只是少一个入口，不影响使用。

## 用法

1. 点右上角 ♪；
2. 「我的 → 登录」，扫码或粘贴 Cookie（Cookie 只存在 Host 侧，不进浏览器）；
3. 「漫游」直接听，不用登录也行；
4. 想调音质 / 音效 / 歌词样式，点播放条右侧 🎚 进「设置」。

面板本身可以拖着走：拖标题栏移动、拖左边缘改宽、拖下边缘改高、双击标题栏复位。

标题栏右边有个**📌 固定**按钮：固定后位置换算成相对右/下边缘的 em 值，缩放窗口时面板贴着原来的角、按同样比例缩放；再点一次解除固定。

如果不小心把面板拖到窗口外面了，**点一下右上角的音符图标**就会把它呼唤回默认位置（不会只是关掉）。

## 它怎么工作的（给想看的人）

```
index.js            Host 半：注册路由、持有 Cookie
lib/weapi.js        网易云 weapi 加密（AES-128-CBC ×2 + RSA）与请求
lib/actions.js      动作表：登录、搜索、歌单、点赞、音质、歌词…
lib/routes.js       POST /netease-music/api · GET /netease-music/audio（Range 透传）
lib/store.js        Cookie 持久化
src/*.js            浏览器半（IIFE 挂在 NT 命名空间上，构建时拼成一个文件）
client.js           构建产物
```

几个当时脑子还算在线的决定：

* **Cookie 永不进浏览器**：所有接口调用都由 Host 转发，页面只跟同源 `/api` 说话。
* **音频优先直连 CDN**：CDN 带 `Access-Control-Allow-Origin: *`，`<audio>` 直接播 CDN 地址 +
  `crossOrigin="anonymous"`，Web Audio 照样能接；探测失败才退回本地代理。
  这样每秒 1MB 的流不用挤过 Node 的单线程，跟 agent 抢 CPU。
* **二维码自己画**：`src/10-qr.js` 是个自包含 QR 编码器（byte 模式、EC M、版本 1–10），
  因为 unikey 每次都变，图片托管又不可达。
* **混响按需挂载**：1.9 秒 IR 的 ConvolverNode 湿声为 0 时也在逐块卷积，是这条链最贵的节点，
  所以湿声归零就断开连接。
* **歌词翻译按时间戳容差匹配**：`tlyric` 和原文时间戳差几十到几百毫秒，±0.45s 内取最近。

## 已知的坑（诚实版）

* **VIP 独占 / 无版权曲目听不到**。这是版权授权，不是客户端能绕的；本项目只做了
  「请求档位被锁 → 自动降档到能播的最高档」以及「试听片段提示」。
* 面板浮在 `shell.overlay` 上，桌面壳的原生窗口按钮、其他插件的高层浮窗（余额挂件之类）
  可能盖住它；面板可以拖走，这是最省事的解法。
* 歌词背景层的 `z-index: -1` 依赖宿主当前的层叠结构，换版本可能会跑到内容上面（那就不好看了）。
* 播放卡不卡取决于你的机器、壁纸是否在动、以及你有没有开混响。

## 等比缩放

界面里没有写死的像素：整张样式表都是相对 `.ntm-root` 的 `em`，而那个 `font-size` 是
`clamp(11.5px, 0.65vw, 15px)` —— 窗口越宽，面板、字号、间距、图标一起变大，反之一起收。
只有 1px/2px 的描边保留字面值，因为发丝线不该跟着放大。

拖动缩放的上下限也按当前的 `font-size` 换算，不是固定 320/720。

## 开发

```bash
node build-client.mjs     # src/*.js -> client.js
node test-host.mjs        # 起临时服务，真打网易云接口 + Range 音频
node smoke-client.mjs     # jsdom 里挂载真实 client.js，跑点击流程
node test-qr.mjs          # 二维码生成后用 zxing-cpp 解回来（需要 python segno / zxing-cpp）
```

改 `client.js` 之后刷新页面即可（链接安装，不用重装）。
